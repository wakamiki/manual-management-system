## 1. テスト概要

### 1-1. テスト目的

本システムが仕様通りに動作し、業務運用上の誤操作を防止できることを確認する。

確認対象

* 正常動作
* 異常系
* 権限制御
* 状態遷移
* UI表示
* DB整合性

### 1-2. テスト対象

* 画面機能
* API機能
* DB連携
* 認証 / 認可
* 権限制御
* レスポンシブUI

### 1-3. テスト分類

* 単体テスト
* 結合テスト
* 画面テスト
* APIテスト
* 権限テスト
* 状態遷移テスト
* DB確認テスト

## 3. 共通テスト観点

### 3-1. 正常系

* 登録
* 更新
* 一覧取得
* 詳細取得
* 検索
* 状態変更

### 3-2. 異常系

* 必須未入力
* 文字数超過
* 不正状態遷移
* 権限不足
* 存在しないID
* 利用停止データ

### 3-3. UI系

* メッセージ表示
* disabled制御
* 確認ダイアログ
* レスポンシブ

### 3-4. データ整合性

* FK整合性
* approvedAt制御
* createdAt保持
* updatedAt更新 
* changeNote履歴保存
* createdByUser整合性

### 3-5. DTO / バリデーション系

* `@NotBlank` / `@NotNull` / `@Size` の検証
* categoryId 未選択時の入力エラー
* changeNote 未入力時の入力エラー
* 複製時 status 許可値（DRAFT / PENDING）の検証

### 3-6. ボタン表示 / disabled 制御

* 状態別ボタン表示
* ロール別ボタン表示
* 作成者本人承認禁止時の disabled 表示
* 使用停止カテゴリ時の操作制限表示
