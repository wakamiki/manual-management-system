## 2. 画面遷移

### 2-1. 基本遷移
```text
ログイン画面
  -> トップ画面
     -> マイページ
     -> マニュアル詳細画面
     -> マニュアル入力画面
     -> ユーザー管理画面
     -> カテゴリ管理画面
```

### 2-2. 別タブ運用
- `詳細を見る` は別タブで開く
- `編集` は入力画面を編集モードで別タブ表示する
- `複製` は入力画面を複製モードで別タブ表示する
- `新規作成` は入力画面を新規モードで別タブ表示する
- 管理画面は親画面を閉じずに作業できるよう別タブで開く

## 4. SCR-002 トップ画面

### 4-1. 表示内容
- 検索フォーム
- カテゴリ絞り込みフィルタ
- ステータス絞り込みフィルタ
- 新規作成ボタン
- ホームアイコン
- 通知バッヂ
- カテゴリ一覧
- 使用停止中カテゴリ
- マニュアル一覧
- ページネーション
- 一覧には以下を常時表示する
  - マニュアルID
  - カテゴリ名
  - タイトル
  - コンテンツ
  - ステータス
  - 更新履歴日
  - 最終アップデート日
  - 更新者
  - チェンジノート
  - 作成者

### 4-2. ホームアイコン
- 左下に配置する
- クリックでマイページへ遷移する
- Bootstrap Icons の `house-fill` を使う

### 4-3. 通知バッヂ
- 上段: 差し戻し通知件数
- 下段: 未承認通知件数
- 差し戻しはオレンジ
- 未承認は緑
- 承認通知はバッヂ表示しない

### 4-4. 一覧操作
- 詳細を見る
- 編集
- 複製

### 4-5. 検索条件
- カテゴリはコンパクトなドロップダウン内で複数選択できる
- ステータスはコンパクトなドロップダウン内で複数選択できる
- アーカイブ検索は独立チェックボックスではなく、ステータス絞り込みに含める
- カテゴリ選択肢は `すべて / 営業部 / 経理部 / 総務部` とする
- ステータス選択肢は `すべて / 下書き / 申請中 / 承認済 / アーカイブ` とする
- 複数項目を同時にチェックして一括検索できる

### 5-1. 日時表示ルール
- 作成日は日付中心で表示する
- 更新日時は時間まで表示する

### 5-2. ボタン表示
- 下書き
  - 編集（作成者専用）
  - マニュアル公開
  - 複製
  - アーカイブ
- 申請中
  - 承認
  - 差し戻し
  - アーカイブ
  - 複製
- 承認済
  - 複製
  - アーカイブ
- アーカイブ
  - 複製
  - 復帰

### 5-3. 補足
- 差し戻し / アーカイブ / 復帰は入力画面で `changeNote` を入力してから確定する
- 復帰対象は承認日時を持つアーカイブ済マニュアルとする

## 6. SCR-004 マニュアル入力画面

### 6-1. 画面名
- `manual-form`

### 6-2. モード
- 新規
- 編集
- 複製
- 差し戻し
- アーカイブ
- 復帰

### 6-3. 入力項目
- manualId
- title
- content
- category
- changeNote
- updatedAt
- historyChangedAt
- historyChangedByUser
- createdAt
- status

### 6-4. ボタン
- 下書きに保存
- マニュアル公開
- 承認
- 差し戻し
- アーカイブ
- 復帰

### 6-5. 補足
- 旧 `manual-create` / `manual-edit` は廃止
- 見た目は旧編集画面をベースに統一する
- 新規モードでは `マニュアルID / 作成日時 / 更新日時 / 作成者` は表示しない
- 編集モードと複製モードでは `マニュアルID / 作成日時 / 更新日時 / 作成者 / 履歴日時 / 履歴作成者 / ステータス` を表示する
- 入力画面内には複製ボタンを置かない
- `下書きに保存` では `PENDING → DRAFT` を許可する
