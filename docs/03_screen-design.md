## 2. 画面遷移

### 2-1. 基本遷移
```text
ログイン画面
  -> トップ画面
     -> マイページ
     -> マニュアル詳細画面
     -> マニュアル入力画面
     -> ユーザー管理画面

```

### 2-2. 別タブ運用
- `詳細を見る` は別タブで開く
- `編集` は入力画面を編集モードで別タブ表示する
- `複製` は入力画面を複製モードで別タブ表示する
- `新規作成` は入力画面を新規モードで別タブ表示する
- 管理画面は親画面を閉じずに作業できるよう別タブで開く

## 4. SCR-002 トップ画面

### 4-1. 表示内容
- 検索フォーム
- カテゴリ絞り込みフィルタ
- ステータス絞り込みフィルタ
- 新規作成ボタン
- ホームアイコン
- ログイン中ユーザー名
- 通知バッヂ
- クイックビュー
- カテゴリ一覧
- 使用停止中カテゴリ
- マニュアル一覧
- ページネーション
- 一覧には以下を常時表示する
  - マニュアルID
  - タイトル
  - ステータス
  - 更新日
  - 作成者
  - カテゴリ
- アコーディオン展開時に以下を表示する
  - コンテンツ
  - 更新履歴

### 4-2. ホームアイコン
- 左下に配置する
- クリックでマイページへ遷移する
- Bootstrap Icons の `house-fill` を使う
- アイコンの右側にログイン中ユーザー名を表示する

### 4-3. 通知バッヂ
- 上段: 差し戻し通知件数
- 下段: 未承認通知件数
- 差し戻しはオレンジ
- 未承認は緑
- 承認通知はバッヂ表示しない

### 4-4. 一覧操作
- 詳細を見る
- 編集
- 複製

### 4-5. 検索条件
- カテゴリはコンパクトなドロップダウン内で複数選択できる
- ステータスはコンパクトなドロップダウン内で複数選択できる
- アーカイブ検索は独立チェックボックスではなく、ステータス絞り込みに含める
- カテゴリ選択肢は `営業部 / 経理部 / 総務部` とする
- ステータス選択肢は `下書き / 申請中 / 承認済 / アーカイブ` とする
- 複数項目を同時にチェックして一括検索できる
- 初期表示では `下書き / 申請中 / 承認済` を選択済みにし、`アーカイブ` は未選択とする
- 使用停止カテゴリはカテゴリフィルタ内で `使用停止中` のミニ開閉にまとめる

### 4-6. 左サイドバー
- 左サイドバーは検索条件入力ではなく、クイックビューと補助ナビゲーションとして扱う
- クイックビューには以下を表示する
  - 自分の作成分
  - 申請中
  - 最近更新
- 各クイックビュー項目には件数を表示してよい
- カテゴリ一覧はサイドバー下段の補助ナビとして残す
- 使用停止中カテゴリはサイドバー内でも折りたたみ表示とする

## 5. SCR-003 マニュアル詳細画面

### 5-1. 表示内容
- マニュアルID
- タイトル
- カテゴリ名
- ステータス
- 作成日
- 更新日時
- 作成者名
- 本文
- 更新履歴
- 履歴日時
- チェンジノート
- 更新者名

### 5-2. 更新履歴表示
- 各履歴行には `履歴日時 / 更新者名 / チェンジノート` を表示する
- 更新者名は更新履歴の各行で確認できるようにする

### 5-3. 日時表示ルール
- 作成日は日付中心で表示する
- 更新日時は時間まで表示する

### 5-4. ボタン表示
- 編集（作成者専用）
- 複製
- マニュアル公開
- 承認
- 差し戻し
- アーカイブ
- 復帰

### 5-5. 補足
- 差し戻し / アーカイブ / 復帰は詳細画面でインライン入力した `changeNote` を使って確定する
- 差し戻し / アーカイブ / 復帰のインライン入力パネルは共通UIとし、操作名と確定ボタン文言だけ切り替えてよい
- 画面上の入力ラベルは `changeNote` ではなく `更新履歴` と表示してよい
- 承認はボタン押下時に `履歴コメントを残しますか` の確認ダイアログを表示してよい
- 承認ダイアログで `はい` を選んだ場合は詳細画面でインライン入力を開き、コメント付き承認とする
- 承認ダイアログで `いいえ` を選んだ場合はコメントなしで承認してよい
- 復帰対象は承認日時を持つアーカイブ済マニュアルとする

## 6. SCR-004 マニュアル入力画面

### 6-1. 画面名
- `manual-form`

### 6-2. モード
- 新規
- 編集
- 複製

### 6-3. 入力項目
- manualId
- title
- content
- category
- changeNote
- updatedAt
- createdAt
- createdByUser

### 6-4. ボタン
- 下書きに保存
- マニュアル公開
- 承認

### 6-5. 補足
- 旧 `manual-create` / `manual-edit` は廃止
- 見た目は旧編集画面をベースに統一する
- 新規モードでは `マニュアルID / 作成日時 / 更新日時 / 作成者` は表示しない
- 編集モードと複製モードでは `マニュアルID / 作成日時 / 更新日時 / 作成者` を表示する
- 入力画面内には複製ボタンを置かない
- `下書きに保存` では `PENDING → DRAFT` を許可する
- 差し戻し / アーカイブ / 復帰は `manual-form` ではなく詳細画面のインライン入力で扱う
